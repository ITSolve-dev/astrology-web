# Telegram WebView

Специфика среды Telegram Mini App.

## Ключевые особенности

- Бесшовная авторизация через Telegram — без логинов и паролей
- `initData` передаётся на бэкенд для аутентификации
- Все взаимодействия с Telegram API делегируются бэкенду
- Горизонтальный свайп на iOS закрывает TMA — избегать горизонтальных каруселей

## Viewport

При запуске вызывать `tg.expand()` для перехода в полноэкранный режим.

## Safe Areas

Нижняя навигация учитывает safe area через CSS-переменные:

```css
padding-bottom: env(safe-area-inset-bottom);
```

## Темизация

CSS-переменные Tailwind привязываются к `themeParams` Telegram при инициализации. Поддерживаются светлая и тёмная темы.

## Кнопка «Назад»

Управление `tg.BackButton` — на уровне роутера. Видимость и обработчик клика меняются при навигации между страницами.

## Push-уведомления

Через Telegram-бота, не нативные. Реализуются на бэкенде.
